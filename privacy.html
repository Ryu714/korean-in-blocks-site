Privacy Policy

Korean in Blocks Tools · Effective October 24, 2026

Who uses this app

Korean in Blocks Tools is used only by the owner of the YouTube channel Korean in Blocks (@KoreaninBlocks) to manage that channel. It is not available to the public.

What data it accesses

With the owner's permission (Google OAuth, scope youtube.force-ssl), the app reads comments on the channel's own videos, including the public display name and channel ID of each commenter, and can post replies to those comments.

How the data is used and stored

  • Data is used only to read and reply to comments on the channel's own videos.
  • The OAuth token and a small log of handled comment IDs are stored on the owner's computer. Nothing is stored on any server operated by this app.
  • Data is not sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account security page: myaccount.google.com/permissions.
